# Examples

What one run of Thursday's story produced on the [live site](https://covered-coop.pages.dev), on the PayPal sandbox. Every person is fictional. Every id starting with a capital letter and digits is a real sandbox id. `scripts/walk.ts` plays the story and `scripts/examples.ts` saves these files.

| File | What it is |
|---|---|
| [income-statement-marek.json](income-statement-marek.json) | Marek's statement: each visit, its hours, his pay and its PayPal transaction id |
| [landlord-link-marek.json](landlord-link-marek.json) | What a landlord sees from the signed link: months, hours and totals, with no household names or addresses |
| [dispute-evidence-okafors.json](dispute-evidence-okafors.json) | The cooperative's answer if the Okafors dispute the charge: the terms, the check-in and check-out times, and every PayPal id |
| [late-cancel-lindqvist.json](late-cancel-lindqvist.json) | The money rows of Mr. Lindqvist's late cancellation: the hold, the fee captured, and the payout |
